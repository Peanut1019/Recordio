# Overview

In order to further my learning, I sought to learn about mobile applications rather than just web ones. This is the other coding language used for mobile apps that I learned for this purpose.

To use the app, add a recording instance and add tracks that you want to record to it. Once you want to record, click on the recording instance banner and in the next screen, hit "Start Recording".

In order to become accustomed to using Swift, I created a project with a few views, some local data handling, and implemented a few package dependancies.
